# Typetorist: The Twinflame

This is a Unity project for the game **Typetorist: The Twinflame**.

## Project Structure

- **Animations/**  
  Contains animation assets for bosses, player, portals, and UI.

- **Interface/**  
  Contains interface scripts, such as `ITyper.cs`.

- **Palletes/**  
  Prefabs for different palette themes (e.g., Default, Evil Dungeon).

- **Prefabs/**  
  Prefabs for game objects including player, bosses, bullets, portals, and UI elements.

- **Resources/**  
  Reserved for runtime-loaded assets.

- **Scenes/**  
  Unity scene files for different game screens and levels:

  - `HomeScreen.unity`
  - `Scene1.unity`, `Scene2.unity`, `Scene3.unity`
  - `DedScreen.unity`, `FinishedScreen.unity`, `PauseScreen.unity`

- **Scripts/**  
  C# scripts for gameplay logic, audio, spawning, and more.

- **Settings/**  
  Project and game settings.

- **Sound Effects/**  
  Audio assets for game effects.

- **Sprites/**  
  Sprite assets for UI and gameplay.

- **TextMesh Pro/**  
  Fonts, shaders, and resources for advanced text rendering.

- **Textures/**  
  Texture assets for environments and objects.

- **Tiles/**  
  Tile assets for level design.

- **Unity.VisualScripting.Generated/**  
  Auto-generated files for Unity Visual Scripting.

## Getting Started

1. **Open the Project:**  
   Open the `.sln` or `.csproj` file in Unity Hub or your IDE.

2. **Scenes:**  
   Start with `HomeScreen.unity` for the main menu.

3. **Play:**  
   Press Play in the Unity Editor to run the game.

## Requirements

- Unity Editor version: See [ProjectSettings/ProjectVersion.txt](../ProjectSettings/ProjectVersion.txt)
- TextMesh Pro package

- All assets and scripts are organized by function for easy navigation.
